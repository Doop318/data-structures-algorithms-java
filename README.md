# Data Structures & Algorithms in Java (COMP2026)

This repository serves as a comprehensive portfolio of my implementations and problem-solving workflows for **COMP2026 Applied Data Structures** at Deakin University. It showcases deep structural program optimization using Java.

## 📈 Algorithms & Data Structures Covered
* **Linear Data Structures:** Custom implementations of Arrays, Linked Lists, Stacks, and Queues.
* **Non-Linear Data Structures:** Binary Trees, Binary Search Trees (BST), Heaps, and Graph Representations.
* **Core Algorithms:** Sorting (Merge Sort, Quick Sort), Searching (Binary Search), and Graph Traversal (BFS, DFS).
* **Complexity Analysis:** Rigorous assessment of Time and Space complexity using Big O notation for every solution.

## 🛠️ Development Environment
* **Language:** Java (JDK 17+)
* **Tools:** Integrated Development Environments (IDEs) & Command Line tools
